# Assets de marca

| Arquivo            | Origem                                     | Uso                                 |
| ------------------ | ------------------------------------------ | ----------------------------------- |
| `fly-wing.png`     | `ASA FLY.png` do acervo da Fly             | Ícone do botão central Minha Viagem |
| `fly-wordmark.png` | `fly company logo horizontal - branca.png` | Cabeçalho                           |

Ambos são **brancos sobre transparente**, de propósito: o React Native tinge
com `tintColor`, o que permite usar a mesma arte em dourado (botão central) ou
branco (cabeçalho) sem duplicar arquivo.

Ao receber o manual final da marca (pendência §50.2), substitua estes arquivos
mantendo o mesmo nome e a mesma característica de arte branca sobre alfa.
